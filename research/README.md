# research/

Extract and verify information before any script is written. No video starts
without a verified source.

## Method

1. Start from the public URL the owner gives (Roblox Newsroom, official
   Roblox blog, creator announcement, reputable press).
2. Read the full page — never trust a headline or a snippet.
3. Write down, for each claim: the exact wording, what it measures, the date,
   and the URL.
4. Cross-check numbers with a second source when the claim is a number
   (players, visits, revenue, dates).
5. Flag anything unconfirmed as **unconfirmed** — it never becomes narration.

## Rules

- Never invent facts about games or creators.
- Two numbers that measure different things are never compared without
  labelling both measures.
- A rumour, a leak or a tracker label is labelled as such, never as official.
- Keep the filled brief (`brief-YYYY-MM-DD-<slug>.md`) next to the video's
  `metadata.json`.
