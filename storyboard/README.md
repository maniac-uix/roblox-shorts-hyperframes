# storyboard/

Scene-by-scene breakdown. One storyboard per video, written before any
composition is edited.

## Rules

- One scene = one idea = one distinct visual. Never reuse the same visual
  for two scenes.
- Every scene has motion (something draws, pops, travels or parallaxes).
  A zoomed still card is a failure.
- Key text inside the safe zone (x 120–888, y 288–1248). Captions at the
  bottom of the band. Titles ≥ 110 px, subtitles ≥ 70 px.
- Text only where the lower third is calm/dark enough to read it.
- Transitions on the voice beats (6–8 frames: whip-pan, zoom-blur or
  glitch), never a hard cut on a sentence.
